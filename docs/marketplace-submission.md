**插件简介**  
ecc-workflow 是一个面向 Cursor 的 Spec-driven（规格驱动）开发插件，覆盖从需求分析到代码实现的 5 阶段流程，并内置持续学习机制，帮助团队把“对话式编码”升级为“可复用、可审查、可迭代”的工程流程。

**核心能力**  
- 5 阶段开发流程：需求分析、任务规划、架构设计、规格撰写、代码实现  
- 全套组件：rules、skills、agents、commands、hooks  
- 质量门禁：通过规则和命令引导阶段审查与交付一致性  
- 持续学习：支持项目学习、习惯沉淀与工作流演化

**适用人群 / 场景**  
- 使用 Cursor 的个人开发者与小团队  
- 需要规范化研发流程、提升交付质量的项目  
- 希望将 AI 开发流程标准化、文档化的团队

**安装方式**  
- Marketplace 搜索：`ecc-workflow`  
- 或在 Cursor Chat 中执行：`/add-plugin ecc-workflow`

**安全与合规说明**  
- 插件内容为提示词、规则与流程文档，不包含恶意脚本  
- hooks 用于开发提示与自动化提醒，可按项目需要启用或关闭  
- 不要求额外敏感权限，不上传用户私有代码数据

**维护状态**  
- 当前状态：active maintenance（持续维护）
